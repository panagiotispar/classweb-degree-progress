# 🎓 Διαδραστική Πορεία προς το Πτυχίο
Μια εφαρμογή που παίρνει το Excel από το ClassWeb και οπτικοποιεί την πρόοδό σου!

👉 **[ΠΑΤΗΣΤΕ ΕΔΩ ΓΙΑ ΝΑ ΑΝΟΙΞΕΤΕ ΤΗΝ ΕΦΑΡΜΟΓΗ](https://classweb-degree-progress-mcrvhutauic9qopscamdww.streamlit.app/)** 👈

## Οδηγίες Χρήσης
1. Κάνε είσοδο στο **ClassWeb** του Πανεπιστημίου Ιωαννίνων με τους ιδρυματικούς σου κωδικούς.
2. Από το πλαϊνό μενού, πλοηγήσου στις **Βαθμολογίες** και επίλεξε **Η Καρτέλα μου**.
3. Στη σελίδα που θα ανοίξει, βρες το εικονίδιο του **Εξαγωγή σε Excel** (πάνω αριστερά από τον πίνακα βαθμολογίας) και πάτα το.
4. Άνοιξε το link της εφαρμογής (παραπάνω).
5. Ανέβασε (drag & drop) το αρχείο `H καρτέλα μου - Όλα τα μαθήματα.xlsx` που μόλις κατέβασες στο ειδικό πλαίσιο της εφαρμογής.
6. Εξερεύνησε τα διαδραστικά σου γραφήματα!
